# תסריט דמו ללקוח — מערכת ניהול לקוחות ויתרות

זמן יעד: **6–8 דקות**. כל הנתונים בדויים. התסריט נבדק מקצה לקצה —
כל מספר שמופיע כאן הוא מה שבאמת יקרה על המסך.

---

## הכנה (פעם אחת, לא מוקלט — ~5 דקות)

```bash
npm run db:up
npm run demo:fixtures     # יוצר את שלושת קובצי הדמו ב-fixtures/
npm run demo:reset        # מנקה דאטה, שומר משתמשים, קובע תאריך חתך 10/08/2026
npm run build && npm start  # שרת פרודקשן — מהיר ובלי סימני פיתוח בפינה
```

> אם `npm run dev` שלך רץ — עצור אותו קודם (Ctrl+C), שניהם על פורט 3000.

1. היכנס למערכת (localhost:3000) עם המשתמש שלך.
2. **ייבוא לקוחות** ← העלה `fixtures/demo-clients.xlsx` ← אישור וייבוא
   (12 לקוחות; שורת השגיאה מכוונת — נשתמש בה גם בהקלטה).
3. **הגדר תעריפים** ל-6 לקוחות (לקוחות ← שם ← עריכה ← תעריף חודשי ← שמירה):

   | לקוח | תעריף |
   |---|---|
   | אבי מזרחי | 1200 |
   | מור לוי ושות בע"מ | 950 |
   | דנה ברק | 1600 |
   | יוסי פרץ | 1800 |
   | חן פרץ | 1500 |
   | אלון מור אחזקות בע"מ | 2500 |

4. **אל תריץ** חיוב חודשי ואל תעלה דפי חשבון — את זה עושים מול המצלמה.
5. הגדרות הקלטה: זום דפדפן 110–125% (Cmd+פלוס), חלון נקי בלי סרגל
   סימניות, מצב "נא לא להפריע". הקלטה: **Cmd+Shift+5** ← בחר אזור ←
   הפעל מיקרופון לקריינות. (רוצה השהיות באמצע? Loom מאפשר Pause.)
6. עשה חזרה יבשה אחת. לחזרה נוספת: `npm run demo:reset` וחזור על 1–3.

## תסריט ההקלטה

### פרק 1 — הלקוחות (דקה)

1. פתח את **לקוחות** — הרשימה המלאה על המסך.
   🎙️ "כל הלקוחות מהאקסל הקיים שלך — המערכת מייבאת אותו, לא מחליפה אותו."
2. פתח את הכרטיס של **אבי מזרחי** — הצג פרטים, תעריף, יתרה.
3. *(אופציונלי, 30 שנ')* עבור ל**ייבוא אקסל**, העלה שוב את
   `demo-clients.xlsx` — הצג את מסך המיפוי ואת **דוח השגיאות**:
   "לקוח ללא מספר זהות — חסר ת"ז".
   🎙️ "שורה בעייתית לא מפילה כלום — היא מדווחת, והשאר נקלט."
   לחץ "אישור וייבוא" (יציג "עודכנו 12" — הייבוא בטוח להרצה חוזרת).

### פרק 2 — יתרות פתיחה וחיוב חודשי (דקה)

4. **יתרות פתיחה** — הזן 2–3 יתרות ברצף עם **Enter**: הקלד סכום,
   Enter, השדה הבא כבר מסומן. שים לב ל-✓ הירוק וליתרה שמתעדכנת.
   🎙️ "שלושים לקוחות — שתי דקות הקלדה. פעם אחת בהקמה."
   הצג את באנר **תאריך החתך**.
   🎙️ "תנועות בנק עד התאריך הזה לא ייספרו — כי הן כבר בתוך היתרה שהזנת. אין ספירה כפולה."
5. **יתרות** ← לחץ **"הרץ חיוב חודשי"** — טוסט ירוק: "נוצרו 6 חיובים".
   🎙️ "בפרודקשן זה רץ לבד באחד לכל חודש. לחיצה חוזרת לא תיצור כפול — נסו."
   *(אפשר ללחוץ שוב: "אין חיובים חדשים — 6 כבר קיימים".)*

### פרק 3 — קליטת דף חשבון (שיא ראשון, 2 דקות)

6. **קליטת דף חשבון** ← העלה `fixtures/demo-bank-1.csv`.
   מסך הביניים יציג: **8 תנועות זכות · 6 חדשות · 2 הוחרגו אוטומטית ·
   1 שורת חובה סוננה**. גלול על הטבלה: החזר מס הכנסה והעברה בין
   חשבונות מסומנים "מוחרגת" עם הסיבה.
   🎙️ "המערכת לא סומכת על אף אחד — קודם מראה מה היא עומדת לעשות, ורק אחרי אישור קולטת."
7. לחץ **אישור וקליטה** — הטוסט יסכם: 3 הצעות לאישור, 3 לתור הידני.
8. עבור ל**תור אישורים**:
   - שלוש שורות עם הצעה "ביטחון גבוה" והלקוח כבר מסומן (אבי מזרחי,
     מור לוי ושות, דנה ברק) — לחץ **שייך** על כל אחת.
     🎙️ "המערכת זיהתה לפי שם. ומרגע שאישרתי — היא זוכרת את חשבון הבנק של המשלם."
   - **משפחת פרץ, ‏3,300 ₪** — לחץ **פצל**: 1,800 ליוסי פרץ, 1,500
     לחן פרץ. המונה מתאזן ← **פצל ואשר**.
     🎙️ "העברה אחת שסוגרת שני תיקים — מפוצלת בשניות."
   - **א.מ. אחזקות, ‏2,500 ₪** — לא זוהה שם. בחר ידנית "אלון מור
     אחזקות בע"מ" ← **שייך**.
   - **הפקדת מזומן ‏400 ₪** — לחץ **"לא תשלום לקוח"**.
   - לחץ **"אשר את כל המותאמות (4)"** — טוסט: "4 תשלומים אושרו".
9. חזור ל**קליטת דף חשבון** והעלה **שוב** את `demo-bank-1.csv`:
   **0 חדשות, 8 כבר טופלו**.
   🎙️ "אי אפשר לקלוט תשלום פעמיים. גם אם הקובץ יעלה שוב בטעות."

### פרק 4 — הלמידה (השיא, דקה)

10. העלה את `fixtures/demo-bank-2.csv` ("שבוע אחרי") ← אישור וקליטה.
11. פתח את **תור אישורים**: שלוש התנועות מזוהות **אוטומטית, "ודאי"** —
    כולל "מזרחי אבי" (שם הפוך!) ו"א.מ. אחזקות בעמ" (כתיב שונה).
    🎙️ "שם אפשר לכתוב באלף צורות — חשבון בנק לא. אחרי אישור אחד, כל
    תשלום עתידי מהחשבון הזה מזוהה בוודאות. ככל שעובדים — היא לומדת."
12. לחץ **"אשר את כל המותאמות (3)"** — קליק אחד, שלושה תשלומים נרשמו.
    🎙️ "אלה תשלומי ספטמבר מראש — הלקוחות האלה נכנסים לזכות, והחיוב של החודש הבא יתקזז מולם אוטומטית."

### פרק 5 — התמונה המלאה (דקה)

13. **יתרות** — עצור על **דנה ברק: שילמה 800 מתוך 1,600 — יתרה 800 ₪
    פתוחה**.
    🎙️ "תשלום חלקי לא הולך לאיבוד — רואים בדיוק מי סגר, מי חלקית, ומי לא שילם."
14. **יומן ביקורת** — גלול: כל פעולה שעשינו בסרטון רשומה — מי, מתי,
    מה, מאיזו כתובת. סנן לפי "תנועות בנק".
    🎙️ "מערכת של רואה חשבון — הכול מתועד, כלום לא נמחק."
15. סיום מול מסך היתרות.
    🎙️ "העלית דף חשבון, אישרת, והיתרות של כל המשרד מעודכנות. בלי להקליד סכום אחד ידנית."

## מה לא להבטיח בסרטון

- ❌ "זיהוי אוטומטי מלא מהיום הראשון" — ביום הראשון טבלת הכינויים
  ריקה וכמעט הכול ידרוש אישור. ההתכנסות לוקחת שבועות. המסר הנכון:
  **"המערכת לומדת מכל אישור — ותוך זמן קצר רוב העבודה אוטומטית."**
- ❌ הנפקת מסמכים/קבלות — זה שלב ב'. אם נשאל: "השלב הבא בתוכנית."
- ❌ חיבור ישיר לבנק — הקליטה היא ייצוא ידני, וזו החלטה מכוונת.
