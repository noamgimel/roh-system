# מערכת ניהול לקוחות, יתרות והנפקת מסמכים — משרד רו"ח

מערכת פנימית למשרד רואה חשבון: רשומת לקוחות, מעקב יתרות, קליטת דף חשבון בנק,
התאמת תנועות ללקוחות והנפקת מסמכים דרך ספק חיצוני (פייפרלס / Sumit).

האפיון הטכני המלא: `docs/tech-spec.md`.

## סטאק

- Next.js (App Router, TypeScript, Tailwind) — ממשק וצד שרת
- PostgreSQL — Supabase בפרודקשן, Docker מקומי בפיתוח ובבדיקות
- vitest — בדיקות אינטגרציה מול DB אמיתי

## הרצה מקומית

```bash
npm install
npm run db:up        # מרים Postgres מקומי (פיתוח + בדיקות) ב-Docker
npm run db:migrate   # מריץ מיגרציות על DB הפיתוח
npm run dev          # שרת פיתוח — http://localhost:3000
```

`.env.local` נדרש (ראה `.env.example`):

```
DATABASE_URL=postgres://roh:roh@localhost:54329/roh
```

## בדיקות

```bash
npm run db:up   # אם עוד לא רץ
npm test
```

הבדיקות רצות מול DB ייעודי (פורט 54330, tmpfs) — כל ריצה מתחילה מסכימה נקייה.
כל הפיתוח והבדיקות על **נתונים ממוסכים בלבד** — אין נתוני אמת בריפו ובבדיקות.

`npm run fixtures` יוצר קובצי דוגמה ממוסכים לבדיקה ידנית של המסכים:
`fixtures/bank-sample.csv` (דף חשבון בקידוד windows-1255, כמו מהבנק) ו-
`fixtures/clients-sample.xlsx` (אקסל לקוחות).

## מבנה

```
db/migrations/        מיגרציות SQL — רצות לפי סדר שמות הקבצים
src/lib/              לוגיקה עסקית (db, migrate, audit, clients/)
src/app/              מסכים ו-API (App Router)
tests/                בדיקות אינטגרציה + עזרי בדיקה
scripts/migrate.ts    הרצת מיגרציות מה-CLI
```
